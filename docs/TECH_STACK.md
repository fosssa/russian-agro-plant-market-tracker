# Технологический стек проекта

В этом разделе кратко перечислены основные технологии, используемые в проекте, сгруппированные по назначению.

## Backend и API

- Python 3.12
- FastAPI (REST API и приложение бекенда)
- Pydantic (валидация и сериализация данных)
- SQLAlchemy (ORM и работа с базой данных)
- Celery + Redis (фоновая обработка задач и планировщик)

## База данных и ORM

- SQLite в качестве основной СУБД проекта
- SQLAlchemy для описания моделей, связей и миграций на уровне кода

## Frontend и визуализация

- React и React Router для SPA‑интерфейса
- TypeScript для типобезопасной разработки фронтенда
- Vite для сборки и разработки
- Axios для HTTP‑запросов к API
- ECharts / `echarts-for-react` для интерактивной визуализации данных

## Инфраструктура и развертывание

- Docker и Docker Compose для контейнеризации
- Nginx как обратный прокси и сервер статики фронтенда
- Celery Beat / RedBeat для расписаний периодических задач

## Инструменты разработки и качества кода

- BasedPyright / Pyright для статического анализа Python‑кода
- Structlog для структурированного логирования
- TypeScript и ESLint для анализа и контроля качества фронтенда
- Разделение проекта на модули `backend` и `frontend` с отдельными `pyproject.toml` и `package.json`
